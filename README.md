# Internship Feedback Sentiment Analysis

## 📌 Overview

This project performs **Sentiment Analysis** on internship feedback using **Natural Language Processing (NLP)**. The feedback is analyzed using the **NLTK VADER Sentiment Analyzer** and classified into three sentiment categories:

- 😊 Positive
- 😐 Neutral
- 😞 Negative

The project also includes data visualization to better understand the distribution of sentiments.

---

## 🎯 Objective

The objective of this project is to evaluate the emotional tone of internship feedback and classify each feedback as **Positive**, **Neutral**, or **Negative**.

---

## 📂 Dataset

The dataset contains internship feedback collected from different sources.

### Dataset Columns

- Feedback_ID
- Intern_Name
- Department
- Mentor
- Feedback
- Rating
- Source
- Date

---

## 🛠️ Technologies Used

- Python
- Pandas
- NLTK (VADER Sentiment Analyzer)
- Matplotlib
- Jupyter Notebook

---

## 📋 Project Workflow

1. Import Required Libraries
2. Load Dataset
3. Explore Dataset
4. Check Missing Values
5. Check Duplicate Records
6. Perform Sentiment Analysis using NLTK VADER
7. Classify Feedback
8. Visualize Results
9. Export Final Dataset
